# Restaurant Landing Page 🍽️
- A modern, responsive, and high-performance restaurant landing page built with a focus on clean UI/UX. This project showcases authentic Saudi cuisine and features interactive elements like a tabbed About section and a custom mobile navigation system.

# Features
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views using CSS Grid and Flexbox.
- **Interactive Tabs:** A custom-built JavaScript tab switcher for the About, Experience, and Contact sections.
- **Sticky Navigation:** Smart navbar that changes appearance on scroll for better readability.
- **Booking System:** A styled reservation form for customer inquiries.
- **Dynamic UI:** Includes hover effects, badge animations, and Font Awesome integration for a premium feel.

# Tech Stack
**HTML5:** Semantic structure for better SEO and accessibility.
**CSS3:** Custom styling with CSS variables, transitions, and media queries.
**JavaScript :** DOM manipulation for menu toggles, tab switching, and scroll effects.
**Google Fonts:** Poppins, Montserrat, and Raleway for modern typography.
**Font Awesome:** Scalable vector icons.
